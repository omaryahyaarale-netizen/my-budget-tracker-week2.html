# My Budget Tracker - Week 2

This is a simple budget tracker website made with HTML and CSS.

## Features
- Shows list of expenses in a table
- Has 6 expenses: Groceries (450), Bus fare (40), Rent (9000), Movie (500), Airtime (50) Electricity (1500)
- Has form to add new expense
- Has YouTube video tutorial
- Responsive design

## How to use
1. Open index.html in browser
2. See your expenses
3. Use form to add new expense (works in Week 3)
